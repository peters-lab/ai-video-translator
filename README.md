# AI Video Translator

**[AI Video Translator](https://ai-video-translator.com/)** translates, dubs and subtitles videos into 20+ languages. Every speaker keeps their own voice, background music stays intact, and every dub comes with a translated subtitle file.

This is the official public repository for the project by [Peter's Lab](https://peterslab.co/).

🌐 **Available in:** [English](https://ai-video-translator.com/) · [한국어](https://ai-video-translator.com/ko) · [Deutsch](https://ai-video-translator.com/de) · [Français](https://ai-video-translator.com/fr) · [日本語](https://ai-video-translator.com/ja) · [Español](https://ai-video-translator.com/es) · [Português](https://ai-video-translator.com/pt) · [中文](https://ai-video-translator.com/zh)

## Key features

- **Multi-speaker voice cloning:** speakers are detected automatically, and each one is dubbed with a cloned version of their own voice
- **Line-by-line review before dubbing:** split, merge or rewrite lines and fix speaker assignments before any voice is generated
- **Glossary for consistent terms:** lock product names, channel names and technical terms across a whole video series (CSV import and export)
- **Background audio preserved:** voices are separated from music and effects, and the original soundtrack is kept
- **Subtitles included:** translated SRT and VTT files with every dub, burn-in optional
- **Edit without re-paying:** fixing one line only re-voices that line
- **Flexible input:** upload MP4, MOV or WebM, or paste a YouTube link
